# Project: PKM System Setup

## Objective
Implement a simple, portable markdown-based personal knowledge management system that will work across all devices and remain usable for decades.

## Success Criteria
- Folder structure matches PARA + Zettelkasten hybrid
- Templates created for all common note types
- Sync working across desktop and mobile
- Can capture notes quickly from any device
- Weekly review process established

## Tasks
- [x] Create folder structure
- [x] Add templates
- [ ] Set up sync solution (Syncthing or iCloud)
- [ ] Configure mobile quick capture
- [ ] Write first 10 atomic notes
- [ ] Create first MOC
- [ ] Establish weekly review habit

## Notes
The key is starting simple and adding complexity only when feeling specific pain. Most retrieval will happen through search anyway.

Focus on:
1. Quick capture to inbox
2. Regular processing
3. Writing in my own words
4. Liberal linking
