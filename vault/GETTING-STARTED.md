# Getting Started with Your PKM System

Welcome to your new Personal Knowledge Management system.

## Quick Start (5 minutes)

### 1. Choose Your Tool
This vault works with any markdown editor. Popular options:
- **Obsidian** (recommended) - Download from obsidian.md
- **VS Code** with markdown extensions
- **Any text editor** for maximum portability

### 2. Open the Vault
- In Obsidian: "Open folder as vault" → select `/vault` directory
- In other editors: Open the `/vault` folder

### 3. Your First Capture
1. Open `0-Inbox/`
2. Create a new file with any thought
3. Don't worry about organizing - just capture

### 4. Explore Examples
- `Daily/2025-01-14.md` - Example daily note
- `Notes/atomic-notes-improve-retrieval.md` - Example atomic note
- `Notes/pkm-moc.md` - Example Map of Content
- `1-Projects/pkm-system-setup.md` - Example project

## Your First Week

### Day 1-3: Capture Mode
- Write thoughts in Inbox as they come
- Don't organize yet
- Get comfortable with quick capture

### Day 4-7: First Review
1. Read through your inbox items
2. Create 2-3 atomic notes from the best ideas
3. Delete what's no longer relevant
4. Start your first daily note

## Daily Workflow

**Morning** (2 minutes):
- Create today's daily note from template
- Set intention for the day

**Throughout day**:
- Quick thoughts → Inbox
- Don't break flow to organize

**Evening** (5 minutes):
- Add reflection to daily note
- Optionally process 1-2 inbox items

## Weekly Workflow

**Weekly Review** (30 minutes):
1. Process entire inbox
2. Create atomic notes from good ideas
3. Update project status
4. Create/update MOCs if topics are emerging

## Understanding the System

### The Folders

```
0-Inbox/     → Your inbox for everything
1-Projects/  → Things with deadlines
2-Areas/     → Ongoing responsibilities
3-Resources/ → Reference material
4-Archive/   → Completed work
Notes/       → Your atomic notes (the heart)
Daily/       → Journal entries
Templates/   → Starting points
Attachments/ → Images and files
```

### Projects vs Areas

**Project**: Has an end date
- "Write Q1 report" ✓
- "Learn Python basics" ✓
- "Plan vacation" ✓

**Area**: Ongoing responsibility
- "Career development" ✓
- "Health and fitness" ✓
- "Home maintenance" ✓

### Atomic Notes

**One idea per file**. Not one topic, one *idea*.

Good atomic note titles:
- "Atomic notes improve retrieval"
- "Links replace folders for organization"
- "Compound interest accelerates wealth"

Bad note titles:
- "Note-taking" (too broad)
- "Meeting with John" (not an idea)
- "Random thoughts" (not atomic)

## Linking Basics

Create connections with `[[double brackets]]`:

```markdown
The key insight about [[atomic-notes-improve-retrieval]]
is that each note contains one concept. This enables
[[links-replace-folders]] as the organizational mechanism.
```

Don't worry if the linked note doesn't exist yet. Create it when you're ready.

## Common Questions

**Q: Where should this note go?**
A: If unsure, put it in Inbox. Organize during weekly review.

**Q: How many tags should I use?**
A: 3-10 per note. Enough to find it different ways, few enough to maintain.

**Q: Should I use folders or links?**
A: Folders for workflow stages (Inbox → Projects → Archive). Links for connecting ideas.

**Q: What if I want to reorganize later?**
A: That's fine. The system is flexible. Wiki-links update automatically in most tools.

**Q: Do I need to create MOCs right away?**
A: No. Create them when you have 5+ related notes on a topic.

## Troubleshooting

**"I don't know what to write about"**
- Start with daily notes
- Capture meeting notes
- Write about something you learned today

**"My inbox is overwhelming"**
- It's okay. Process 5 items per review session
- Delete liberally - not everything is worth keeping

**"I'm spending too much time organizing"**
- Good! Stop optimizing the system
- Just write notes and link them
- Organization emerges naturally

**"Links feel awkward"**
- Normal at first
- After 20-30 notes, the network effects appear
- Search + links > careful filing
