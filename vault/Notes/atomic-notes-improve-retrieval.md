# Atomic notes improve retrieval

The principle of atomic notes—one idea per file—dramatically improves information retrieval compared to monolithic documents. When each note contains a single, focused concept, the granularity enables ideas to connect across different contexts in ways that topic-based organization cannot achieve.

Consider a note about "deliberate practice." In a traditional system, this might be buried in a 20-page document about "Learning strategies" or "Skill development." Finding the specific concept requires scanning through unrelated content. With atomic notes, "deliberate practice" exists as its own file, making it instantly findable through search and directly linkable from any related context.

The atomic approach also reduces cognitive overhead during note creation. Instead of deciding where in a hierarchical structure a new idea belongs, you simply create a new note with a descriptive title. The organization emerges through links rather than being imposed through folders.

Most importantly, atomic notes enable emergent connections. A note can link to any number of other notes without being constrained by folder hierarchy. The note about "deliberate practice" might link to notes about learning, career development, sports training, and music practice—all simultaneously, creating a web of knowledge that reflects how ideas actually relate rather than forcing them into a single category.
