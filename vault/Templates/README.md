# Templates

Note templates for common types. Use these as starting points.

## Available Templates
- `daily-note.md` - Daily journal entries
- `meeting-note.md` - Meeting notes with action items
- `literature-note.md` - Book/article notes
- `atomic-note.md` - Zettelkasten-style notes
- `project.md` - Project planning and tracking
- `moc.md` - Maps of Content (index notes)

## Using Templates
Most markdown editors support templates:
- **Obsidian**: Core Templates plugin or Templater
- **Logseq**: Template syntax
- **Manual**: Copy/paste and fill in

## Placeholders
- `{{title}}` - Note title
- `{{date:YYYY-MM-DD}}` - Current date
- Replace manually if your editor doesn't support variables
