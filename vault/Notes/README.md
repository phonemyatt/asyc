# Notes

Zettelkasten-style atomic notes stored flat (no subfolders).

## Principles
- One idea per file
- Descriptive titles (not timestamps)
- Written in your own words
- Linked to related notes
- 200-500 words typically

## Naming Convention
Use lowercase hyphenated slugs:
- ✓ `atomic-notes-improve-retrieval.md`
- ✗ `Atomic Notes Improve Retrieval.md`
- ✗ `202501141234.md`

## When to Create a Note
When you can articulate a single, clear concept that:
- You might want to reference later
- Could connect to other ideas
- Is worth preserving in your own words

## Organization
Don't use subfolders. Use:
- **Links** to connect related notes
- **MOCs** (Maps of Content) as navigation hubs
- **Tags** for flexible categorization
- **Search** to find everything else
