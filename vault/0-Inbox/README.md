# Inbox

Quick capture location for all new ideas, notes, and thoughts from any device.

## Purpose
- Capture first, organize later
- Remove friction from note-taking
- Process during weekly review

## Workflow
1. Capture anything here without thinking about organization
2. During weekly review, process each item:
   - Refine into atomic note → move to `/Notes`
   - Project-specific → move to `/1-Projects`
   - Reference material → move to `/3-Resources`
   - Delete if no longer relevant
3. Keep inbox empty or near-empty

The inbox pattern eliminates the "where does this belong?" decision that kills momentum during capture.
